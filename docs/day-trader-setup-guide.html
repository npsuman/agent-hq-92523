Before anything else

Read this first

Not financial advice.

This is software that reads public data and does arithmetic. It cannot see the future. Most people who day trade lose money, and you can too.

  • No order without your yes. Only /trader-broker can lead to an order, and only after a risk PASS, your typed yes and your “Allow once”.
  • Paper trading by default. "paper": true ships in the config. Stay on a paper account until you have watched it work.
  • A simulation, not a prediction. The Time Machine learns from the last 60 days. An earnings report or a halt can do what those days never did.
  • A stop is a plan, not a promise. In a fast market or across a gap, a stop can fill well past its price.
  • Free data, unofficial. Yahoo’s chart data can lag or change. Check anything that matters with your broker.

From the guide’s author: “I’m sharing an open-source tool, not trading advice. I’m not a SEBI-registered adviser. If you need advice, talk to a licensed professional.”

Before you start

What you need

  • Claude Code: the terminal app, the desktop app or an IDE. The skills install and run here.
  • Python 3.8 or newer. Claude runs the tools with it. Nothing to pip install. Check with python3 --version.
  • Your name and email. The SEC tools (news filings, the analyst) ask who is reading. One line in your config.
  • A paper broker account (optional, only to place paper orders): Alpaca or Interactive Brokers. See Connect a broker.

No signup. No API key. No pip install.

Built for US stocks

It scans about 5,900 US-listed stocks and keeps New York time. The market opens at 9:30 AM there, which is 7 PM or 8 PM in India, depending on US daylight saving.

Method A · The easy way

Install: paste, send, done

  1. Paste the link into Claude Code: https://github.com/Jakeschincariol/day-trader-skill
  2. Type install skill and send.
  3. Ready. Claude confirms something like “11 skills installed. Try /trader-scanner”. Wording varies; you want to see all eleven confirmed.

Then try it

/trader-scanner daily

What /trader-scanner hands back:

  • The US list, about 5,900 stocks, from Nasdaq Trader.
  • Setups from daily closes: 20-day breakouts, bull flags, oversold bounces.
  • Opening-range breakouts on 5-minute bars, while the market is open.
  • A watchlist that /trader-news and /trader-entry read next.

Methods B, C and D

Prefer to do it yourself?

Method B: as a plugin (inside Claude Code)

/plugin marketplace add Jakeschincariol/day-trader-skill
/plugin install day-trader-skill@day-trader-skill

Plugin skills get a prefix, for example /day-trader-skill:trader-scanner.

Method C: clone and copy (in your terminal)

mkdir -p ~/.claude/skills
git clone https://github.com/Jakeschincariol/day-trader-skill.git
cp -r day-trader-skill/trader-* ~/.claude/skills/

You get the plain names, like /trader-scanner.

Method D: one project only

Copy the same trader-* folders into .claude/skills/ inside your project instead. (This repository uses method D.)

Not sure? Use A.

It does the copying for you. No Claude Code at all? Paste any one SKILL.md at the top of a chat and it runs as a mode, without the Python tools.

The eleven

The eleven skills: one job each

/trader-scanner: Chart Scanner
Scans thousands of US charts for setups: opening-range breakouts, flags, oversold bounces. Try /trader-scanner orb --at 10:15
/trader-news: News Monitor
Headlines and 8-K filings for every stock you watch, newest first, tagged by what moves it. Try /trader-news TSLA
/trader-entry: Entry Timer
Watches a setup bar by bar. Calls the entry on the first bar that closes above the range. Try /trader-entry TSLA --setup orb
/trader-exit: Exit Planner
Sets your stop and your target before you enter, and refuses a plan that makes no sense. Try /trader-exit --stop or-mid --target 1R
/trader-timemachine: Time Machine
Replays the rest of the day 10,000 times, plus every past day the same setup fired. Try /trader-timemachine TSLA
/trader-budget: Budget Manager
Sizes the trade to your max loss and writes one bracket order: entry, stop, target. Try /trader-budget I only want to risk $50 a trade

And the guards

/trader-risk: Risk Manager
Checks every order against your limits. PASS or BLOCK, with the reason. Try /trader-risk check my order
/trader-broker: Order Executor
Shows the ticket in plain words. Sends it only after your yes. Paper by default. Try /trader-broker set up paper trading
/trader-alerts: Price Alerts
Rings once on your stop, your target, the opening bell and your flat-by time. Try /trader-alerts TSLA 370
/trader-analyst: Earnings Analyst
Reads earnings straight from SEC filings and sums up what changed. Try /trader-analyst TSLA
/trader-pelosi: Pelosi Tracker
Reads Congress’s public stock-trade filings the minute they are posted. Try /trader-pelosi pelosi

Each one reads what the last one wrote

Everything lands in a trader/ folder in your project: the watchlist, the plan, the order, the verdicts. You talk to Claude. Claude runs the Python.

The example · Real data

One trade, end to end

TSLA, Monday October 19 2026. Every number is from the repository’s own example.

  1. /trader-scanner (10:15 AM): 42 of 231 charts had closed above their opening range. TSLA’s range: 354.47 to 362.18.
  2. /trader-news (8:04 AM): “Ahead of Earnings.” Tesla reports this week, so a day trade is out before the report.
  3. /trader-entry (10:15 AM): Triggered on the first 5-minute close above the range, 364.18.
  4. /trader-exit (the plan): Stop 358.32, the range midpoint. Target 370.04, one times the risk. Flat by 3:55 PM.
  5. /trader-timemachine (10,000 replays): Plus 59 real sessions. Verdict: close to a coin flip.
  6. /trader-budget (8 shares): $50 max loss divided by $5.86 risk a share. Loss at the stop: $46.88.
  7. /trader-risk (PASS): Max loss, daily limit, trades a day, reward to risk, entry window.
  8. /trader-broker (your yes): Shows the ticket. You type yes. Claude’s “Allow once” card asks again. Paper account.

Then /trader-alerts watches it. It rings on the stop, the target and at 3:55 PM, to close whatever is still open.

Optional · Paper first

Connect a broker

Every order needs all three:

  1. Risk PASS for this exact order.
  2. Your yes, typed in the chat.
  3. Allow once, on Claude’s own card.

No yes, no order. Every order, every time.

Setup steps

  1. Make paper API keys in the Alpaca dashboard. Paper keys are separate from live keys.
  2. Install uv. It gives you uvx, which runs Alpaca’s server. Instructions at docs.astral.sh/uv.
  3. Add the Alpaca server. Claude Desktop › Settings › Developer › Edit Config. Paste the block from claude_desktop_config.example.json and type your keys into that file.
  4. Restart, then lock it. Customize › Connectors › alpaca. Set place_stock_order to Needs approval. Never “Always allow”.

Keys never go in the chat.

Pasted one by mistake? Delete the message and make new keys. On Interactive Brokers, add its connector from Customize › Connectors and approve orders inside IBKR too.

If it breaks

Quick fixes

/trader-scanner is not found

Installed as a plugin? It’s /day-trader-skill:trader-scanner. Otherwise reopen Claude Code, then run ls ~/.claude/skills | grep trader-

python3: command not found

Install Python 3.8 or newer from python.org. The tools need nothing else.

The SEC tools ask who you are

Add your name and email as sec_user_agent in trader/config.json, or set the SEC_USER_AGENT environment variable.

Prices look late, or a scan stops

Yahoo’s chart data is free and unofficial. It can lag or rate-limit you. Wait, retry, and trust your broker’s price.

My broker still wants $25,000

FINRA dropped the day-trader minimum on June 4 2026, but brokers can phase it in until October 2027. Set "pdt_guard": true.

Update to the latest

Paste the link again and ask Claude to update. Or git pull in your clone and copy the folders again.
